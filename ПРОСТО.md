# Простой способ (без API, токенов и localhost)

## Идея

1. Кладешь картинки в папку **в Dropbox** (на компьютере она синхронизируется сама).
2. Дважды жмёшь **`обновить-работы.bat`** — обновится `works.json`.
3. В **GitHub Desktop** — Commit → Push → сайт на GitHub Pages обновился.

Никаких токенов и API — только папка и GitHub.

---

## Настройка один раз

### 1. Dropbox на ПК

Установи [Dropbox для Windows](https://www.dropbox.com/install).  
Создай папку, например: `Dropbox\Сайт-работы`

### 2. Папка «работы» на сайте

**Вариант А (проще всего):** весь сайт лежит в Dropbox, папка `работы` — внутри него:

```
Dropbox\My site\
  ├── index.html
  ├── script.js
  └── работы\          ← сюда кидаешь картинки
      ├── poster.jpg
      └── wb проект\   ← в имени папки есть wb → блок Wildberries
```

**Вариант Б:** папку `работы` сделать ярлыком на `Dropbox\Сайт-работы` (ПКМ → Создать ярлык → перетащить в папку сайта как `работы`).

### 3. GitHub

1. [GitHub Desktop](https://desktop.github.com/) — добавь репозиторий с папкой сайта.
2. На github.com: **Settings → Pages** → Source: ветка `main`, папка `/ (root)`.

---

## Каждый раз, когда добавил работу

1. Закинул файл в `работы` (через Dropbox — на телефоне тоже ок, дождись синка на ПК).
2. Двойной клик **`обновить-работы.bat`**
3. Обнови страницу в браузере (F5).

> **Важно:** `index.html` сам не меняется — работы подставляет скрипт из `works-data.js`.

4. **На GitHub:** GitHub Desktop → **Commit** → **Push** (нужны `works.json`, `works-data.js` и файлы в `работы/`).

---

## Правила папок

- **Файл в корне** `работы/` (не в папке):
  - на **главной** — до **11 самых новых** картинок;
  - если файлов больше 11 — лишние только на странице **«Все работы»**.
- **Папка** в `работы/` (WB, аватарка, любой проект):
  - на главной **не показывается**;
  - целиком на **«Все работы»** отдельным блоком.
- Папка **`avatarka`** → блок «Аватарка»
- Папка с **wb** в имени → блок Wildberries

После добавления файлов: `обновить-работы.bat` (новые в корне всплывают в топ).

### Подпись к проекту (папка)

В папку проекта положи **`description.txt`** — текст покажется в лайтбоксе при просмотре картинок из этой папки:

```
работы/wb работа_1/description.txt
```

Пример содержимого:
```
Инфографика для карточки товара.
5 слайдов, стиль бренда.
```

Форматы: jpg, png, gif, webp

## Если хочешь вообще без GitHub Desktop

На github.com открой репозиторий → папка `работы` → **Add file** → загрузи картинку.  
Потом на ПК запусти `обновить-работы.bat` и залей только `works.json` через сайт GitHub.
