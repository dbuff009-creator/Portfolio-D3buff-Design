Как проверить

Тестирование адаптивности

1. Откройте сайт в браузере

2. Используйте инструменты разработчика (F12)

3. Включите режим адаптивного дизайна (Ctrl+Shift+M)

4. Проверьте разные размеры экрана

Тестирование производительности

1. Откройте вкладку Performance в DevTools

2. Запишите загрузку страницы

3. Проверьте метрики: FCP, LCP, CLS

Тестирование PWA

1. Проверьте Application → Service Workers

2. Проверьте Application → Manifest
